### Decisions

- DECIDED: live sheet check skipped (installed app running, same bundle id); owner look-and-feel check needed after the PR builds
- DECIDED: `AllRecordingsActions.regenerate` returns `Bool`, false when the row's files are gone, like Open and Show in Finder, and the view sets `TranscriptionsFileNotice.fileMissing` from it. The notice is the window's `@State`, so the presenter reports and the view shows. The task text had the presenter set the notice. Tests `RegenerateSheetStateTests/testARowWhoseFilesAreGoneLeavesTheSheetClosed` and `TranscriptionsViewTests/testARegenerateWhoseFilesAreGoneShowsTheMovedOrDeletedMessage`.
- DECIDED: `present(entry:using:)` takes the regenerator as an argument instead of holding it. The App owns the presenter in `@State`, whose initializer cannot reach `AppState`, and holding it would need `MeetingTranscriberApp.init` to build `AppState` by hand, which moves that construction in the launch order.
- DECIDED: `RegenerateSheetState.allowsChooseFile` is computed as `initialTarget == nil` rather than stored, because only "Regenerate from File…" opens without a meeting, so the two can never disagree.
- DECIDED: the sheet's form inputs travel as `AllRecordingsActions` members (`templateChoices`, `optionsUse`, `chooseFile`, `resolveFile`, `generate`) and the phase as `TranscriptionsView.regenerationPhase`. These are the closures and the value the removed scene passed.
- DECIDED: `ProtocolRegenerationTarget.latest` and its test are deleted together with `ProtocolRegenerator.latestTarget`. Only the removed window read them, and a test-only reader would have kept dead code alive.
- DECIDED: "Regenerate from File…" leaves the "moved or deleted" message as it is because it touches no row file, while a row's Regenerate that finds its files clears it, as Open does.
- DECIDED: the presenter keeps the last opened target in memory after the sheet closes, until the next opening. Nothing leaves the process, and the old window's draft held it the same way.
- ASSUMED: the empty sheet keeps today's "No recent meeting found" line, although the sheet no longer looks for a recent meeting · alternatives: B - "No meeting chosen"; C - "Choose a protocol or transcript" · flip at: `RegenerateProtocolView.noMeeting` · test: `RegenerateProtocolViewTests/testOpenedWithoutAMeetingOffersChooseFileAndCannotGenerate`
